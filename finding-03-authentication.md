# Finding 03 — Authentication

## Severity
High

## Description
Authentication controls should securely verify user identity and protect account-related functionality.

## Impact
Weak authentication controls can allow unauthorized access to protected functionality or accounts.

## Remediation
Use strong authentication controls, secure session management, rate limiting, and appropriate access controls. Never store passwords in plaintext.

## Testing Scope
This finding is documented for authorized web-security training environments only.
